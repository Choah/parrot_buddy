    흰색 window size

    흰색 외곽선은 실제 Parrot Buddy 창 크기입니다. 투명해 보여도 이 영역 안에서는 뒤에 있는 앱 클릭이 막힐 수 있습니다. 크게 만들면 뒤에 켜져 있는 앱이나 창을 클릭하기 어려워질 수 있으니, 가능한 한 앵무새와 상태 박스를 감싸는 최소 크기로 두는 게 좋습니다.

    앵무새와 상태 박스

    앵무새를 그냥 드래그하면 창 전체가 움직입니다. window size가 보일 때만 앵무새 오른쪽 아래 작은 손잡이가 나타나고, 그 손잡이를 드래그하면 앵무새 크기를 조절할 수 있습니다. 지금 크기가 기본값입니다. 상태 박스는 드래그해서 원하는 위치로 옮길 수 있고, 아래 핸들로 크기를 조절할 수 있습니다. 이동하거나 조절하면 흰색 window size는 내용에 맞춰 자동으로 줄거나 늘어납니다. Option + 앵무새 클릭 또는 앵무새 우클릭으로 흰색 window size를 숨기거나 다시 보일 수 있습니다.

    전체 창 이동

    전체 창을 옮기고 싶을 때는 앵무새를 드래그하세요. guide가 열려 있을 때는 Guide 제목 줄을 드래그해도 전체 창을 옮길 수 있습니다.

    window size 조절

    외곽선이 보일 때 모서리를 드래그하면 실제 창 크기를 수동으로 조절합니다. 단, 평소에는 뒤 앱 클릭을 막지 않도록 작게 유지하는 것을 권장합니다.

    가이드 열고 닫기

    흰색 외곽선의 guide 버튼을 누르거나, 앵무새를 빠르게 세 번 클릭하면 이 가이드가 열립니다. 오른쪽 위 × 버튼이나 Esc로 닫을 수 있습니다.

    가이드 옮기기

    Guide 제목 줄을 잡고 드래그하면 Parrot Buddy 창 전체를 옮길 수 있습니다.

    상태 보기

    맨 위 상태 박스에는 현재 잡힌 agent가 폴더 이름으로 전부 표시됩니다. confirm은 확인 필요, working은 작업 중, ready는 켜져 있지만 대기 중입니다.

    상태 박스 숨기기

    상태 박스 오른쪽 위 × 버튼으로 숨길 수 있습니다. 숨긴 뒤에는 앵무새를 한 번 클릭하면 다시 나타납니다.

    메뉴바

    상단 메뉴바의 작은 앵무새 아이콘을 클릭하면 현재 agent 상태가 들어 있는 메뉴가 열립니다. 메뉴에서는 앵무새 창 보이기, 숨기기, 모니터 재시작, 종료를 할 수 있습니다. 작업 중에는 메뉴바 아이콘이 좌우로 흔들립니다.
