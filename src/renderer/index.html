    Guide

    Parrot Buddy

    0

    핵심

    • 흰색 외곽선은 실제 투명 창 크기입니다. 너무 크면 뒤 앱 클릭을 막습니다.
    • 평소에는 앵무새와 작업 상태 창만 감싸는 작은 크기로 두세요.
    • 아래쪽 왼쪽 guide 버튼을 누르면 이 도움말이 열립니다.
    • 오른쪽 위 agent 버튼은 Codex/Claude Code 연결 설정입니다.

    앵무새

    • 드래그: 창 전체 이동
    • 클릭: 조이의 짧은 말풍선 표시
    • 흰색 외곽선이 보일 때 말풍선 양옆 작은 핸들 드래그: 말풍선 폭 조절
    • 길게 누르기: 조이 Assistant 열기
    • 작업 상태 창을 숨긴 뒤 빠르게 3번 클릭: 작업 상태 창 다시 표시
    • 우클릭 또는 Option + 클릭: 흰색 외곽선 숨기기/보이기

    작업 상태 창

    • Codex와 Claude Code가 작업 중인지, 확인을 기다리는지 보여줍니다.
    • 드래그: 작업 상태 창만 이동
    • 아래 핸들: 작업 상태 창 크기 조절
    • 오른쪽 위 ×: 작업 상태 창 숨기기

    조이 Assistant

    • 앵무새를 길게 누르면 열립니다.
    • guide와 같은 큰 패널 크기로 열리고, 창 크기가 자동으로 맞춰집니다.
    • 중요한 일, 일정, 기억할 내용을 정리해 줍니다.
    • 헤더나 빈 영역을 드래그하면 조이 Assistant 창만 이동합니다.
    • 아래 모서리 핸들 드래그: 조이 Assistant 크기 조절

    Agent 상태

    • working: 작업 중
    • confirm: 사용자 확인 필요
    • ready: 켜져 있고 대기 중
    • stopped: 감지된 프로세스 없음
    • 완료는 짹짹 2번, 확인 필요는 짹 1번 알립니다.

    크기 / 위치

    • 작업 상태 창이나 조이 Assistant를 옮기면 창 크기가 내용에 맞춰 자동 조정됩니다.
    • 외곽선 가장자리나 모서리 드래그: 투명 창 크기 수동 조절
    • 말풍선은 앵무새 위치에 따라 왼쪽/오른쪽으로 자동 배치됩니다.
    • Esc: guide, 조이 Assistant, agent 설정, 창 크기 조절 모드 닫기

    메뉴바 / 연결

    • 메뉴바 아이콘: 현재 상태, 창 보이기/숨기기, 재시작, 종료
    • Agent Settings: Codex/Claude Code 감시 켜기/끄기와 경로 설정
    • Codex나 Claude Code를 쓰지 않으면 agent 설정에서 해당 감시를 끄세요.
